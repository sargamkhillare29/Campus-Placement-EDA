# Campus Placement EDA

## Project Overview

This project performs Exploratory Data Analysis (EDA) on campus placement data to understand the factors that influence student placement and salary outcomes.

The analysis focuses on academic performance, technical skills, soft skills, aptitude, internships, projects, work experience, backlogs, and placement status.

## Objectives

- Understand the structure and attributes of the dataset
- Clean the data by handling missing values and duplicate records
- Perform univariate analysis
- Perform bivariate analysis
- Perform multivariate analysis
- Detect and handle outliers using the IQR method
- Study relationships between different variables
- Visualize placement-related patterns using graphs and charts
- Calculate placement-related statistics
- Identify important factors associated with placement and salary outcomes

## Technologies Used

The dataset contains student-related information such as:

- Salary

The project follows these major steps:

1. Data Collection
2. Data Loading
3. Data Understanding
4. Data Cleaning
5. Data Preprocessing
6. Outlier Detection
7. Univariate Analysis
8. Bivariate Analysis
9. Multivariate Analysis
10. Data Visualization
11. Results and Discussion
12. Conclusion

## Visualizations

Different visualization techniques are used to understand patterns and relationships in the dataset, including:

- Histograms
- Box plots
- Scatter plots
- Count plots
- Heatmaps

## Key Insights

The analysis explores how technical skills, aptitude, communication skills, internships, projects, work experience, academic performance, and backlogs are associated with placement outcomes and salary.

The project report indicates that practical exposure and skill-based competencies are important factors to examine along with academic performance.
